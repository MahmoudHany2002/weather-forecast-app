# توثيق تطبيق الطقس

هذا الدليل يوفر معلومات مفصلة حول تطبيق الطقس، بما في ذلك هيكل المشروع، المكونات الرئيسية، وكيفية استخدام التطبيق.

## هيكل المشروع

```
lib/
├── Models/
│   └── weather_model.dart       # نموذج بيانات الطقس
├── cubits/
│   └── get_weather_cubit/       # إدارة حالة التطبيق
│       ├── get_weather_cubit.dart
│       └── get_weather_states.dart
├── services/
│   └── weather_services.dart    # خدمات API للطقس
├── views/
│   ├── Home_view.dart          # الشاشة الرئيسية
│   └── search_view.dart        # شاشة البحث
├── widgets/
│   ├── no_weather_body.dart    # واجهة الترحيب
│   └── weather_info_body.dart  # عرض معلومات الطقس
└── main.dart                   # نقطة الدخول للتطبيق
```

## المكونات الرئيسية

### 1. نموذج البيانات (Models)
- `WeatherModel`: يمثل بيانات الطقس بما في ذلك اسم المدينة، درجة الحرارة، والحالة الجوية.
- `ForecastDay`: يمثل توقعات الطقس ليوم معين.

### 2. إدارة الحالة (State Management)
- `GetWeatherCubit`: يدير حالة التطبيق ويتعامل مع طلبات الطقس.
- `WeatherStates`: يحدد الحالات المختلفة للتطبيق (أولي، تحميل، نجاح، فشل).

### 3. الخدمات (Services)
- `WeatherServices`: يتعامل مع طلبات API للحصول على بيانات الطقس.

### 4. الشاشات (Views)
- `HomeView`: الشاشة الرئيسية التي تعرض معلومات الطقس.
- `SearchView`: شاشة البحث عن المدن.

### 5. الويدجت (Widgets)
- `NoWeatherBody`: يعرض شاشة الترحيب عندما لا توجد بيانات طقس.
- `WeatherInfoBody`: يعرض معلومات الطقس التفصيلية.

## كيفية استخدام التطبيق

1. عند فتح التطبيق لأول مرة، ستظهر شاشة الترحيب.
2. انقر على زر البحث في الشريط العلوي للانتقال إلى شاشة البحث.
3. أدخل اسم المدينة في حقل البحث أو اختر من المدن الشائعة.
4. بعد البحث، سيعرض التطبيق معلومات الطقس الحالية وتوقعات الأيام القادمة.
5. يمكنك العودة إلى شاشة البحث في أي وقت للبحث عن مدينة أخرى.

## الميزات المستقبلية

- دعم الموقع الجغرافي للحصول على طقس الموقع الحالي
- إضافة خرائط الطقس
- دعم وضع الليل (Dark Mode)
- إضافة إشعارات للتحذيرات الجوية
- دعم اللغات المتعددة
